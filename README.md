# Claude Code Workspace

A personal workspace for experimenting with [Claude Code](https://claude.ai/claude-code) — Anthropic's AI-powered coding assistant.

## What's here

- `.claude/` — Claude Code project settings and configuration

## Getting started

1. Install [Claude Code](https://claude.ai/claude-code)
2. Open this folder in your terminal
3. Run `claude` to start a session
